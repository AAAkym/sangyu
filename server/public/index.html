桑榆智伴

服务运行中 · 端口 3000 本地开发模式 · JSON 文件存储

双端微信小程序（家属端 / 适老化老人端）的本地后端。Express + JSON 文件模拟数据库， 接口路径与后期微信云函数一一对应，迁移时小程序侧只需修改 miniprogram/utils/request.js。 本页展示的入口、文案与接口均取自小程序真实代码。

本地联调指南

身份与地址

  • Mock 身份（miniprogram/utils/config.js）：家属 mock_family_001、老人 mock_elder_001
  • 小程序 BASE_URL：http://localhost:3000（miniprogram/utils/request.js）
  • server/data/relationships.json 已预置两身份的监护关系，家属端开箱即可看到老人告警

启动与自检

  • 启动后端：cd server && npm start
  • 一键自检全部接口：npm run smoke（需先启动服务）
  • 开发者工具需勾选「不校验合法域名」（设置 → 项目设置 → 本地设置）
  • 服务状态 JSON：GET /healthz（含各 JSON 文件记录数）
  • 数据落盘：server/data/*.json，可随时查看 / 手动清理
