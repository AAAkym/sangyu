- **根因**：老人端 tabBar 只有 1 个 tab，无 mine 入口；且 mine 是 tabBar 页，`navigateTo` 微信层面禁止跳转。
- **修复**：elder 首页 Hero 右上角新增三横线「设置」入口（`wx.switchTab` 跳 mine，未触碰 tabBar 结构）；mine 页双角色化——老人端显示身份卡 + 已绑定家属 + 「切换为家属身份」+ 退出登录；`setSelected` 按角色适配（elder→0 / family→1）。
- **验证**：老人端 → 设置 → 退出 → 选家属 → 进家属首页 ✅；反向同理 ✅；退出时清 Storage 角色并停止轮询 ✅。

- **根因**：演示工具按钮平铺页底，演示中易误触；误触后 toast 打扰并污染演示数据。
- **修复**：health 页新增「演示工具（联调用）」折叠区（默认收起），两个 Mock 按钮移入，显式展开后才可点击；数据加载本身为 silent 请求，无任何自动 toast。
