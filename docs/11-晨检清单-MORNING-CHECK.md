# 晨检清单（MORNING-CHECK）· 批次 16

> 用途：夜间批次收尾后、答辩演示前，由真人按顺序过一遍的 8 项目检。
> 用法：每项做完把 ☐ 改成 ✅；任何一项失败，记录现象到本文末尾「异常记录」，先修再演示。
> 预置条件：`cd server && npm start`（3000 端口），微信开发者工具打开 `miniprogram/`，编译模式选「演示模式」。

## ① 每个页面滑到最底 ☐
逐页进入（老人端：首页 / 健康 / 提醒 / 消息 / 我的；家属端：首页 / 告警 / 报告 / 我的），滑到最底，确认：
- 内容完整可达，没有最后一屏被 tabBar / 安全区遮住半行字
- 空态页（无告警 / 无预约时）有插画与引导文案，不是白屏

## ② 老人端双 tab ☐
老人身份登录 → 首页底部 tabBar 应只有 **[首页, 我的]** 两个 tab；点「我的」高亮正确，点「首页」返回正确。家属端同为双 tab，切换身份后高亮不串。

## ③ 聊天键盘不顶破 ☐
进入语音陪伴页 → 点输入框唤起键盘 → 确认输入栏随键盘上移、聊天区自动滚到最新一条 → 发一条消息，气泡不被键盘挡住。收起键盘后布局复位。

## ④ 编辑资料同步 ☐
「我的」→ 点头像 → 改称呼：保存后头部称呼立即更新；换预设头像色块或从相册传图：头像立即更新；杀掉小程序重进，资料仍在（存服务端）。

## ⑤ 语音包面板 ☐
「我的」→ 语音播报开关可开可关（有 toast 反馈）；语音陪伴页顶部来源标识正常（星火生成 / 本地陪伴 / 离线陪伴 三态之一）。注意：真实语音识别与播报（TTS/ASR）为计划外能力，当前为打字聊天，勿在演示中承诺语音对话。

## ⑥ 特大字号 + 高对比不破版 ☐
「我的」→ 字号设「特大」→ 开高对比 → 逐页目检：文字不溢出卡片、按钮不换行错位、告警红色与底色仍可区分。检查完切回「标准 / 标准对比」。

## ⑦ 品牌符号（logo）显示 ☐
登录页顶部品牌区应显示「双弧环 + 琥珀菱形」符号图（assets/brand/symbol.png），不是空白；「我的」页未设头像时头像圈显示同款符号兜底。素材源文件在 `brand/`（appicon-512.png 深底白弧版 / appicon-512.png 浅底深弧版）与 `miniprogram/assets/brand/symbol.svg`。

## ⑧ 真机 healthz ☐
手机与电脑连同一 Wi-Fi，手机浏览器访问 `http://<电脑IP>:3000/healthz`，应返回 `{"code":0,...,"status":"running"}`；再在小程序真机预览中确认首页数据能加载。若失败：检查 Windows 防火墙 3000 端口入站规则与电脑 IP 是否变化。

## 已知演示注意点
1. **设备 10 分钟离线**：种子设备最后上报固定在 `demo:reset` 时刻，超过 10 分钟家属首页会显示「离线」。这是真实模拟逻辑；演示超 10 分钟时可重跑 `npm run demo:reset`（会重置全部演示数据）或现场用「记录一条健康数据」刷新上报时间。
2. 星火大模型接口不通时陪伴对话自动降级为「本地陪伴 / 离线陪伴」，属正常三级降级，不是故障。
