## P0-A 老人端底部导航栏修复 ✅ 通过

- **问题**：老人端进入「我的」后，tabBar 只剩「首页」一个且无高亮——custom-tab-bar 老人端列表只有 [首页]，mine 页无对应 tab 可高亮。
- **根因**：组件按角色只渲染 [首页]；mine 页 setSelected(0) 指向首页造成"高亮错位"。
- **修改**：custom-tab-bar/index.js + .wxml + .wxss——
  1. 全量 tab 定义 `ALL_TABS`（roles 标注可见角色），按角色生成 tabs（union + hidden 显隐，不用 wx:if 重建）；
  2. 选中态改为 **selectedPage（页面路径）** 判定，不再依赖序号（彻底消除高亮错位）；页面 onShow 仍传序号，组件按可见列表解析；
  3. 选中态多通道：主色文字 + 加粗 600 + **顶部指示条**（scaleX 弹性动画，不只靠颜色）；
  4. 顶部 1rpx 分隔线（--color-border 令牌）保留；
  5. tab 项与文字加 `transition: 200ms var(--ease-out)`（color/transform）。
- **验证**：老人端 首页高亮 → 我的 高亮且双 tab 仍在 → 首页回得去；家属端同样正常（代码路径复核）。smoke 两遍 122/122。
