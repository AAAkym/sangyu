## 后续工作如何进行
1. **日常开发**：改代码前先看 00 总结报告与 01 审查报告；改完跑 `cd server && npm run demo:reset && npm run smoke && npm test`，全绿再收工。
2. **夜间批次**：开工建 `.nightly.lock`（含 hash 基线）+ 备份目录 + 追加根目录 NIGHTLY-JOURNAL.md；收尾产出验收报告进本目录（下一个编号），日志归档副本同步进本目录，删除锁。
3. **演示准备**：演示当天早上按 11 晨检清单逐项过；演示数据异常就重跑 `npm run demo:reset`。
4. **文档规约**：所有报告/总结/清单类 Markdown 一律存进本目录，文件名用中文说明"干了什么、什么用途、如何进行"；代码与配置不进本目录。
